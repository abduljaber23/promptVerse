## 🎯 Format de chaque fiche de révision

Pour chaque question du jury, vous retrouvez 3 blocs ultra-clairs :
1. **Explication simple** : Pour comprendre l'idée en 1 phrase sans jargon.
2. **Dans votre code** : L'emplacement et l'exemple exact dans votre projet.
3. **🗣️ À dire à l'oral** : La phrase parfaite à prononcer devant le jury avec l'assurance d'un professionnel.
