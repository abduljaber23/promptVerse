## 📌 Présentation du Sprint

- **Modalité** : **Projet Solo CDA**
- **Durée** : 7 Jours

---

## 🎯 Objectifs du Sprint
Construire l'interface web Single Page Application (SPA) en React TypeScript et conteneuriser l'ensemble des composants du système.

1. **Frontend React SPA** : Développement des vues (Landing, Catalogue, Fiche Produit, Formulaire de vente, Dashboard Achats/Gains) avec Tailwind CSS Dark Mode.
2. **Context Auth & Axios** : Interception du token JWT et gestion de la session utilisateur.
3. **Conteneurisation Docker** : Écriture des multi-stage `Dockerfile` (API & Web) et orchestration dans `docker-compose.yml`.
